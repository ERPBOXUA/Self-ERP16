Self ERP - Ukrainian company integrator of complex automated solutions for business development and management based on Odoo 17 Enterprise

This module allows you to set up Accounting for Ukraine to:
1. Ensure compliance with the registration of economic transactions and accounting requirements of Ukrainian legislation regarding accounting and tax accounting.
2. Expand the Odoo toolkit for management accounting by current practices prevalent in Ukraine.

The module adds to Odoo's Settings options to help you choose a package or individual functionality.
Packages allow you to install the entire pre-configured set in one selection.
Functionality is distributed among packages according to the following criteria:
A. Business direction:
- B2B,
- IT,
- IT - resident Action City.
B. Defined functionality set:
- Accounting for Ukraine in the maximum configuration
- Accounting for Ukraine
- Accounting for Ukraine for sole proprietors VAT payers
- Accounting for Ukraine for sole proprietors
Experts can directly select the necessary functionality:
- Settlements accounting with counterparts, fund accounting
- Foreign economic activity
- VAT
- Payroll
- Fixed assets
- Inventory
- Reporting
- Printed forms for Ukraine

This module also allows you to register a database with installed Accounting for Ukraine to access updates that ensure:
- Obtaining new functionality
- Compliance with Ukrainian legislation
- Operational effectiveness of Accounting for Ukraine on current Odoo releases
- Upgrades to new versions of Odoo
